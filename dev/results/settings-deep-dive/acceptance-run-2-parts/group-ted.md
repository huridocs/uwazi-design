Commit under test: playground 956db631, served at http://localhost:1438/. Date: 2026-10-05. Scripts: `acceptance-run-2-parts/group-ted-scripts/` (`run-all.sh` runs them in order; results in `results.jsonl`, later lines override earlier ones; `assemble.py` builds the table below). Screenshots: `acceptance-run-2-shots/<name>.png` (file names in the Shot column).

Scope: TED-01 to TED-109 plus the X rows the page's Applies line lists (X-01 to X-09, X-12, X-13; X-10 and X-11 are N/A). No check has Needs M9, `defer` or `drop`, so nothing is SKIP. Needs F1 to F4 and M1 to M8 were all driven, against Sample unless a row says otherwise (CEJIL for TED-76, Travesía for TED-77, Artworks for TED-71).

How the runs were driven and read:
- Every check ran in a fresh browser context at 1280x800 (phone checks at 390x844 with touch). Dark mode and light mode for X-07, X-08 and the visual look at 1280 and 390.
- Console errors during a check are a FAIL of that check, except the Jotai "atomFamily is deprecated" warning. One React error, "Encountered two children with the same key ... Judgment", is logged each time the Court Case editor opens; it is recorded once, on TED-16, and not repeated on every Court Case check.
- Phone dialogs: the harness `open(..., "mobile")` uses Chromium `isMobile` emulation. In that mode the app sets `--kb` to 1189px on load (`useKeyboardInset` computes `innerHeight - visualViewport.height` once, while the viewport reports 844 after load), which pads every bottom-anchored dialog to zero height, so no dialog is visible (property panel, Add thesaurus, Dashboard "Reset demo data" confirm). Phone dialog checks (TED-33, TED-109, X-06, X-07 at 390) were therefore driven in a 390x844 touch viewport without `isMobile` (`openPhone` in `ted-lib.mjs`). The emulation result is recorded on TED-33 with a screenshot.
- Where a check could not use the stated data: TED-71 needs an image file to pick and the Sample has none (Files tab takes PDFs), so it was driven on Artworks; TED-76 has no CEJIL template with a plain Date range (Juez y/o Comisionado has two Multiple date ranges); TED-77 has no Travesía template with both a date range and a geolocation (VIOLENCIAS has a Multiple date ranges and a geolocation; two others have a Date range).
