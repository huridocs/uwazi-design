Target: playground 73a13827 at http://localhost:1438/. Driven with Playwright, desktop 1280x800 and phone 390x844 touch, one fresh context per check group. Scripts: `group-e-scripts/` (`run-all.sh` re-runs everything; `assemble.py` builds this file from `results.jsonl`). Screenshots are in `../acceptance-run-1-shots/`.

Run notes:

- Console: no console errors or page errors in any check on the three pages. The jotai warning "atomFamily is deprecated" prints on every page load and is not counted.
- Switching the data source from the navbar leaves Settings for the Library in this app, so checks that switch source reopen Settings afterwards (X-13, X-02 switch route, THS-06).
- There is no failure switch, so the "An error occurred" paths (X-04 failure, FLT-12, THS-37, REL-15 failed save) were not driven.
- On the Sample, the relationship-type registry survived a tab reload (REL-05, X-01); thesauri did not (THS-09, THS-40, X-01).
- The "Cancel" button on the thesaurus and relationship-type editors leaves without the discard dialog even when the form is dirty (THS-36, REL-15, X-02).
- "Library reader" checks (FLT-16 to FLT-18) were skipped as another unavailable item, not tested.
