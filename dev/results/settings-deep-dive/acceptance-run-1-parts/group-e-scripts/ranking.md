
## FAILs ranked by severity

Owner: Code = behaviour or data, Design = layout, copy or accessibility. Check ids are page-scoped (X rows are written X-nn per page).

1. Code. Thesauri data does not persist: a thesaurus created (THS-09, THS-40) or a value edited (X-01 on Thesauri) is gone after a tab reload. Filters and Relationship types persist.
2. Code. Thesaurus saves accept bad data silently: duplicate thesaurus name stored (THS-08), duplicate labels at the same level stored (THS-19), an unnamed or empty group dropped or saved with no item and no message (THS-13), no inline "This field is required" (THS-07).
3. Code. Dirty editors lose edits without warning: the footer Cancel on the thesaurus and relationship-type editors leaves with no discard dialog, and Escape does nothing on the relationship-type editor (THS-36, REL-15, X-02 on both pages). The guard dialog copy also differs ("Discard unsaved changes?", "Keep editing"/"Discard" instead of "Discard changes?", "Cancel"/"Discard changes") on all three pages (X-02). Copy is Design; the unguarded Cancel is Code.
4. Code. Relationship-type delete does not follow decision G6: Settings offers "Move references to" and deletes a type that references use (REL-11), no bulk selection or "Selected n of 5" bar on Relationship types and Thesauri (REL-12, REL-13, X-12 on both pages), delete dialogs lack the quoted header, text and buttons (REL-09, THS-27, THS-28).
5. Code. Thesaurus editor lacks most of the tree editor: no click-to-edit values, Escape cancel or Enter-to-next-row (THS-11), Add item ignores the focused row and does not take focus (THS-12), no Move to group (THS-14), no Sort (THS-17), no Collapse/Expand all (THS-18), no selection or Selected n of m (THS-20); label whitespace is not collapsed (THS-12).
6. Code. Thesaurus CSV import and export are absent (THS-29 to THS-33).
7. Code. Large thesaurus is not virtualised and has no value search or A-Z jump: "Municipios" renders all 2,443 inputs, and Add item appends 2,443 rows below the viewport without focus (THS-34, THS-35).
8. Code. Thesauri and Relationship types lists: no sorting by Label and no default name order (THS-01, REL-01); Thesauri has no Templates column or pills (THS-01).
9. Code. Filters groups are inline chips, not the group model in the checklist: no Add group dialog with templates multi-select (FLT-04), no name validation or duplicate check (FLT-05), no group Edit action (FLT-06), no group rows to collapse or expand and no "Empty group" drop target (FLT-10). An empty group is dropped on Save without telling the user (FLT-13). The footer count adds property rows to templates ("16 filters shown" for 9 templates) (FLT-22). The Properties table is writable, has Values and Group columns and no template column (FLT-23).
10. Code. Relationship type feedback: create and rename notifications do not name the type or the old and new name (REL-05, REL-07, X-04 on REL), the new row is not highlighted or scrolled into view (REL-05, REL-15).
11. Design. Accessibility: duplicate accessible names for row buttons and inputs ("Move up" x16, "Move down" x16 on Filters; "Item label" x6, "Add item" x3 on the thesaurus editor) (FLT-08, X-07 on Filters and Thesauri); Move buttons do not carry the template name and focus is lost to the body after a keyboard move (FLT-08); no keyboard reorder on the thesaurus editor (THS-16). Moderate/minor axe findings on the delete dialog (landmark-no-duplicate-banner) and empty table headers are not failures.
12. Design. Copy: Filters page has no banner "Filters configuration", still says "Types" and "entity types" (FLT-01); empty state `No templates listed. The Library shows every template.` missing (FLT-20); Beacon texts differ from the quoted Uwazi text ("Library filters updated" vs "Filters saved", "Thesaurus created" vs "Thesauri added.", "<name> saved" vs "Thesauri updated.", "<name> deleted" vs "Thesauri deleted") (FLT-12, THS-09, THS-10, X-04 on all three pages); relationship-type commit button reads "Create relationship type" not "Add" (REL-04); thesaurus name placeholder is "e.g. Violation types" not "Thesauri name" (THS-07).
13. Design. Phone: thesaurus value tap opens no sheet with Move to group, Move up/down and Remove (THS-38); relationship-type edit opens a full page, not a sheet (REL-22).
14. Design/Code. Relationship types Manage modal in the Relationships panel has no rename, and its delete confirm does not say references are set to "No label" before the action (REL-17, REL-19).
