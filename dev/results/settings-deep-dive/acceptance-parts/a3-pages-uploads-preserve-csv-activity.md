# Acceptance checks: Pages, Uploads, Preserve, Import CSV, Activity log

Part A3 of the Settings acceptance checklist. Column format, tags, test setup and X-01 to X-13 are in `00-front.md` and are not repeated here. Written 2026-10-04 from `gap-matrix-row-ids.md`, the Decisions table in `page-briefs.md` and `uwazi-settings-inventory.md` ("copy from inventory" below means the quoted text is from the inventory section of that page).

Conventions used in this file:

- `[UX]` with no number is an improvement from a Design finding that has no UX number in the audit list; the GM row names the finding.
- Rows whose Target is `keep (proto-only)` are included, tagged `[PO]`, when the Target text names concrete behaviour to keep (PAG-13, UPL-04, UPL-05, CSV-01, ACT-04, ACT-07).
- Excluded by rule: `drop` and `defer` rows, Decision G9 (Preserve keeps only the token card), G10 limits (custom CSS applies only in Pages and public preview; JS is stored and never run), G14 (no Data visualizations).
- Needs: `D1a`, `D1c`, `D1d` in a gap row are store dependencies; they are written here as `F1`. Seed data named in Pre comes from `data/settings.ts` and `data/imports.ts`.
