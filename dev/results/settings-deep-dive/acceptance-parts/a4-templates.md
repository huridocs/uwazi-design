# Acceptance checks: Templates list and Template editor

Check ids are numbered per page. The GM column holds gap-matrix row ids (`gap-matrix-row-ids.md`) and is independent of the check number. Needs `M8` means the Settings editor must write the template store. `M2`, `M3a`, `M3b`, `M4`, `M5`, `M6`, `M7` name the step that must land for the change to reach forms, records, cards, columns or Library filters. Where a check lists several steps, all of them must have landed.
