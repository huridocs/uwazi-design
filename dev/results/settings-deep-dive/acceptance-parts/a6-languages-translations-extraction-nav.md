# Acceptance checks: Languages, Translations, Metadata extraction, Paragraph extraction, Navigation

Part a6 of the Settings acceptance checklist. Column format, tags and test setup are in `00-front.md`. X checks are not repeated here. Check ids are sequential per page. The GM column names the gap-matrix rows each check covers. Rows named `<PAGE>-PO<n>` are the prototype-only rows that Decisions keep (listed in the gap matrix under "Prototype-only"); they are numbered here in table order.

Conventions used below:
- "Beacon" means the Beacon drawer in the navbar (notifications and tasks).
- "Dev panel" is the developer panel in the component catalog (logo toggles the catalog) that flips the current role and each feature flag (NAV-15). Default: role admin, all flags on.
- "(copy from inventory)" marks Uwazi text taken from `uwazi-settings-inventory.md` where no brief exists.
- Where the brief gives no exact Design copy for an improvement, the Expect cell describes the content and does not quote.
